# 毎週月曜、やることをテキストで残す

あとで「今週やることは？」と聞くと AI が答えてくれます。テキストでログを残しておくからです。

毎週月曜に **「今週やること」** と **「来週に延ばしたこと」** を書いておくと、AI がリマインドしてくれます。

## 書き方
- 「誰が何をするか」をそのまま書く
- 自分宛ての DM に送っておくだけでも OK（あとでここに貼る／AI に渡す）
- 音声入力のままで大丈夫

## 使い方
```bash
./scripts/new-week.sh          # 今週の weekly/YYYY-MM-DD.md を作る（先週の延期分を自動で引き継ぎ）
./scripts/new-week.sh 2026-10-05  # 日付を指定して作る
```

Claude Code では次のように話しかけるだけで使えます（`weekly-log` スキル）。
- 「今週やること書いて：田中さんは見積もり、自分は資料の修正…」
- 「今週やることは？」
- 「先週延ばしたことって何だっけ？」

## 例（Slack／DM に投稿する文面）
```
【今週やること】
- 田中：A社の見積もり提出
- 自分：提案資料の修正
【来週に延ばしたこと】
- 自分：B社への連絡（先方不在のため）
```
