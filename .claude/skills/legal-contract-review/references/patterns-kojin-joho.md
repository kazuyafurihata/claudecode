# 個人情報取扱に関する契約・覚書 指摘パターン

## 1. 責任範囲の但し書き

**指摘想定**：
> 責任範囲を限定する但し書きを必ず追加してください。
> 自社の責に帰さない事由による損害まで無制限に負わされるべきではありません。

**標準文例**：
```
前項の事故が乙の本覚書違反に起因する場合において、
甲が情報主体又は甲の顧客等から損害賠償請求その他の請求を受けたときは、
甲は乙に対し、その解決のために要した費用（損害賠償金を含むが
これに限定されない）を合理的な範囲で求償することができる。
なお、当該求償権の行使は、甲の乙に対する損害賠償請求権の行使を
妨げるものではない。
但し、乙の責に帰すべき事由によらずに生じた損害についてはこの限りではない。
```

## 2. 送信アドレスの運用

**指摘想定**：
> 送信アドレスは個人のものを使うのが通常です。
> メールの運用を確認しておいてください。

**運用ルール**：
- 法務への送付は**個人アドレス**から
- 部門共通アドレス（○○_team@writeup.co.jp）はNG
- 送信元アドレスと申請者が一致していることを法務が確認

---

## 3. 取扱目的の明確化

**指摘想定**：
> 個人情報の取扱目的を具体的に明記してください。
> 包括的・抽象的な記述は避けてください。

**標準文例**：
```
乙は、本覚書に基づき甲から提供を受ける個人情報を、
以下の目的のためにのみ取り扱うものとする。
 (1) 甲のプライバシーマーク更新に伴う取引先情報セキュリティ体制の確認
 (2) 個人情報保護法に基づく合同監査
 (3) ○○業務の遂行

乙は、前項に定める目的以外の目的で個人情報を取り扱ってはならない。
```

---

## 4. 安全管理措置

**指摘想定**：
> 乙（受託者）が講じる安全管理措置の内容を具体的に記載してください。

**標準文例**：
```
乙は、個人情報保護法第23条及び個人情報保護委員会のガイドラインに従い、
個人情報の漏洩、滅失、毀損を防止するため、以下の安全管理措置を講じる。

(1) 組織的安全管理措置
    ① 個人情報取扱責任者の任命
    ② 個人情報取扱状況の定期的な点検

(2) 人的安全管理措置
    ① 従業員への教育・研修の実施
    ② 秘密保持に関する誓約書の取得

(3) 物理的安全管理措置
    ① 個人情報を取り扱う区域への入退室管理
    ② 持ち出し制限

(4) 技術的安全管理措置
    ① アクセス制御（ID・パスワード管理）
    ② 通信の暗号化
    ③ 情報システムの監視
```

---

## 5. 再委託の制限

**指摘想定**：
> 再委託には甲の事前書面承諾を要件化し、再委託先にも同等の義務を課してください。

**標準文例**：
```
乙は、甲の事前の書面による承諾なく、本覚書に基づき取り扱う個人情報を
第三者に開示又は再委託してはならない。

乙は、甲の承諾を得て再委託する場合、再委託先に対し、
本覚書と同等以上の安全管理措置及び秘密保持義務を課し、
乙自らが監督する責任を負うものとする。
```

---

## 6. 事故時の通知・協力義務

**指摘想定**：
> 個人情報の漏洩等事故発生時の通知・協力義務を明記してください。

**標準文例**：
```
乙は、本覚書に基づき取り扱う個人情報について、漏洩、滅失、毀損その他の
個人情報保護法上の事故が発生した場合（又は発生のおそれがある場合）、
速やかに甲に通知し、事故の原因、影響範囲、再発防止策等について
甲と協議し、甲の指示に従って対応するものとする。

乙は、個人情報保護法その他関連法令に基づく報告義務（個人情報保護委員会
への報告、本人への通知等）の履行について、甲に必要な協力を行う。
```

---

## 7. 契約終了時の返還・廃棄

**指摘想定**：
> 契約終了時の個人情報の返還・廃棄と証明書発行義務を明記してください。

**標準文例**：
```
本覚書が終了した場合、又は甲の指示があった場合、乙は速やかに、
本覚書に基づき取り扱う個人情報（複製物・加工物を含む）を甲に返還し、
又は甲の指示に従い廃棄する。

廃棄した場合、乙は廃棄完了日から14日以内に、廃棄完了報告書を
甲に提出するものとする。
```

---

## 8. 監査権

**指摘想定**：
> 監査権の範囲・頻度を合理的な範囲に限定してください。

**標準文例**：
```
甲は、乙における個人情報の取扱状況を確認する必要がある場合、
事前通知の上、年1回を上限として、乙の事業所に立ち入り、
関連資料の閲覧及び関係者への質問を行うことができる。
監査に要する費用は甲の負担とする。

但し、個人情報漏洩事故等の緊急事由が生じた場合は、
本項に定める頻度制限は適用されない。
```

---

## 9. 契約書式（「個人情報取扱いに関する申込」等の文言）

**指摘想定**：
> 「個人情報に関する基本契約書」という名称が正確か確認してください。
> 先方が別の名称を要求する場合は、その文言へ修正してください。

**事例（JAPAN AI案件）**：
- 当初：「個人情報に関する基本契約」
- 修正後：「個人情報を取り扱う業務に関する申込」

---

## 10. 個人情報保護法との整合

**確認ポイント**：
- 委託と第三者提供の区別が正しいか
- 共同利用の場合、共同利用に関する事項（利用目的、管理責任者等）が記載されているか
- 越境移転がある場合、オプトイン方式になっているか
