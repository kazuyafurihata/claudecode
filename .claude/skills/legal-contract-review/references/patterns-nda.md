# 秘密保持契約（NDA）指摘パターン

## 1. 機密情報の定義の重複・不明確

**指摘想定**：
> 機密情報の定義が一部重複しており、文意がやや不明確に見受けられます。実務上の解釈に支障がないか確認してください。

**検出ポイント**：
- 「書面により秘密と指定された情報」と「口頭で秘密と指定された情報」を別条項で重複定義
- 包括的定義と具体的列挙が併記されて競合
- 「公知情報を除く」の但し書きが複数箇所に散在

**改定方針**：定義を一本化。列挙と包括定義のどちらかに揃える。

**標準文例**：
```
第○条（秘密情報）
1. 本契約において「秘密情報」とは、甲又は乙が相手方に対し、書面、口頭、
   電磁的記録その他の方法を問わず、秘密である旨を表示又は通知して開示した
   一切の情報（技術、営業、財務、人事、顧客、取引先に関する情報を含むが
   これらに限られない）をいう。
2. 前項にかかわらず、以下の情報は秘密情報に含まれないものとする。
   (1) 開示を受けた時点で既に公知の情報
   (2) 開示を受けた後、自己の責によらず公知となった情報
   (3) 開示を受けた時点で既に保有していた情報
   (4) 第三者から秘密保持義務を負うことなく正当に取得した情報
   (5) 独自に開発した情報
```

---

## 2. 「本契約の目的」の範囲不明確

**指摘想定**：
> 「本契約の目的」の範囲が不明確なため、実務上の解釈に支障がないか確認したいです。

**検出ポイント**：
- 前文に「各種取引に関する検討のため」等の抽象的記述
- 目的が特定の取引を指すのか業務全般を指すのか曖昧

**改定方針**：具体的な業務名・取引名を明記。

**改定例**：
```
現行：甲乙間の取引に関する検討のため
改定：甲が乙に対してAIコンサルティングサービスを提供するにあたっての事前検討
      及び契約交渉のため
```

---

## 3. 片務／双務の確認

**指摘想定**：
> 先方書式は片務（一方当事者のみが秘密保持義務を負う）になっていますが、
> 当社も秘密情報を開示する可能性があるため双務に修正してください。

**検出ポイント**：
- 「受領者」という呼称が一方のみを想定
- 秘密保持義務を「乙」または「受領者」のみに負わせる構成

**改定方針**：「甲及び乙は、……」の対称形式へ。

**備考**：先方が「要求を受け付けない」スタイルの場合（大手・銀行・官公庁等）、申込書や別紙方式で双務化を図る。

---

## 4. 秘密保持義務の期間

**指摘想定**：
> 契約終了後3年間の秘密保持義務は一般的な範囲です。5年以上を求められた場合は交渉してください。

**許容範囲**：
- 契約終了後2〜3年：標準（受諾可）
- 契約終了後5年：要交渉（正当な理由があれば受諾可）
- 期限の定めなし：原則NG、要交渉

---

## 5. 損害賠償の範囲

**指摘想定**：
> 損害賠償は「直接かつ通常生じた損害に限る」旨を明記してください。間接損害・逸失利益は除外が原則です。

**標準文例**：
```
甲又は乙が本契約に違反して相手方に損害を与えた場合、当該違反当事者は
相手方に対し、直接かつ通常生じた損害に限り、賠償の責めを負うものとする。
但し、故意又は重過失による場合はこの限りではない。
```

---

## 6. 先方修正拒否スタイルへの対応

**指摘想定**：
> 先方が要求を受け付けないスタイルの場合、本NDA本文の修正は困難です。
> 別途、覚書または申込書で当社の懸念を反映できないか検討してください。

**実務的対処**：
- 申込書式で当社の留保事項を記載
- 別紙で「特約事項」を付す
- それでも困難な場合は契約見合わせも選択肢

---

## 7. 再委託・第三者開示

**指摘想定**：
> 再委託や第三者開示には事前の書面承諾を要件化してください。

**標準文例**：
```
受領当事者は、事前に相手方の書面による承諾を得た場合を除き、
秘密情報を第三者に開示又は漏洩してはならない。
本条に基づき秘密情報を開示する第三者に対しては、
本契約と同等以上の秘密保持義務を課すものとする。
```

---

## 8. 返還・廃棄義務

**指摘想定**：
> 契約終了時の秘密情報の取扱い（返還／廃棄／確認書発行）を明記してください。

**標準文例**：
```
本契約が終了した場合、又は相手方からの要請があった場合、
受領当事者は、保有する秘密情報（複製物を含む）を速やかに返還又は廃棄し、
廃棄した場合はその旨を書面で報告するものとする。
```

## 9. 損害賠償条項の欠落（当社雛形にもなかった）

**指摘想定**（村越氏）：
> ひな形に損害賠償の規定がないため追記しています。ひな形の変更を検討してください。

**改定例**：
```
被開示者は、故意または過失によって本契約に違反した場合、これに基づき開示者が被った
通常かつ直接生じた損害を賠償する責任を負う。ただし、逸失利益、機会損失その他の
間接損害及び弁護士費用は含まないものとする。
```
- NDAでは**範囲の限定のみで、上限は設けない**（WU方針）。先方雛形の賠償条項には「（通常かつ直接の損害に限り、逸失利益、機会損失その他の間接損害及び弁護士費用を含まない。）」を挿入する

**出典**：legal:22005 / 22019 / 22034（アビヅ。修正版は新しい雛形として採用）／22041 / 22048（エイブル）

## 10. 業務委託先・関係会社・専門家への開示

- 先方案の「業務委託先には事前承諾なく開示できる。ただし同等の義務を課し、結果について責任を負う」という構造は、双務であれば実務上合理的で**受け入れてよい**（legal:21976）
- 当社案では、関係会社・役員・業務委託先・弁護士／会計士／税理士への開示を認め、守秘義務を負わない開示先には同等の義務を課す（legal:22005）
- 除外事由の第三者取得は「正当な権限を有する第三者から**秘密保持義務を負うことなく適法に**取得した情報」と書く

---

## 11. 「本業務」の定義に「検討」を含める／当事者の表記

- 商談の段階から締結するNDAは、「本業務」に**その検討を含める**。含めないと、商談段階の情報が秘密情報や目的外使用の禁止の対象になるか曖昧になる。受注に至らなかった場合の終期もはっきりする（legal:22048）
- 双務のNDAで「乙は」と書かれた義務は「**受領者は**」に置き換える（legal:22041 / 22048）
- 依頼メールに書いた取引関係（当社が受託するのか）と、甲乙の配置・目的の記載が食い違っていないか確認する（legal:22041）
- 秘密保持の存続期間は3年。同じ相手と過去に結んだNDAとも期間を揃える（legal:21982）
