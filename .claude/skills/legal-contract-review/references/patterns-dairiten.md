# 代理店契約・販売店契約 指摘パターン

## 1. 競業禁止

**指摘想定**：
> 競業禁止はしっかり交渉をお願いします。範囲・期間・対象品目を限定してください。

**許容範囲**：
- 対象品目：本契約商材と直接競合するもののみに限定
- 期間：契約期間中＋契約終了後1〜2年
- エリア：指定エリアに限定

**改定例**：
```
現行：
甲は、本契約期間中及び契約終了後3年間、乙の事前承諾なく、
乙と競合する一切の事業を行わない。

改定：
甲は、本契約期間中及び契約終了後1年間、乙の事前の書面による承諾なく、
別紙に定める本件商材と直接競合する商材の販売代理業務を
第三者のために行ってはならない。
```

## 2. 最低保証の明確化

**指摘想定**：
> 最低保証の支払義務について、顧客都合による解約が発生しても基本契約枠の
> 支払義務が免除されない設計となっています。後日「知らなかった」とならないよう、
> 条文の表現が甲に対して十分明確かご確認ください。

**検出ポイント**：
- 最低保証額・最低保証ID数の記載が抽象的
- 免除事由（不可抗力・サービス停止等）の列挙が不十分

**改定例**（ファインズ案件）：
```
現行：
甲は、月間○○ID分の対価を最低保証として乙に支払うものとする。

改定：
甲は、月間○○ID分の対価（金○○円・税抜）を最低保証として乙に支払う。
但し、以下の事由が発生した場合は、当該月の最低保証を日割り又は免除する。
 ① 乙の責に帰すべき事由によるサービス停止
 ② 不可抗力による提供不能（3営業日以上継続した場合）
 ③ 甲乙合意による一時停止期間
```

## 3. AI誤回答・プラットフォーム変更の免責範囲

**指摘想定**：
> AI回答精度及びプラットフォームの仕様変更・BAN等について乙が
> 一切責任を負わない旨を規定していますが、免責範囲が広すぎると
> トラブル時に当社に不利に働く可能性もあります。条文の妥当性を確認してください。

**改定方針**：
- 乙の故意・重過失の場合は免責対象外とする但し書き
- AI誤回答による直接的な経済損失（顧客からの返金請求等）の扱いを明確化

**改定例**：
```
現行：
乙は、AI回答の精度及びLINE等プラットフォームの仕様変更・BAN等について、
一切の責任を負わない。

改定：
乙は、AI回答の精度及びLINE等プラットフォームの仕様変更・BAN等について、
原則として責任を負わない。但し、乙の故意又は重過失による場合、
並びに乙が本サービスの維持・改善に必要な合理的措置を怠った場合は
この限りではない。
```

## 4. 会社名・押印欄の完成

**指摘想定**：
> 押印欄も完成させてください。会社名等を記載するべきところは記載してください。

**チェック項目**：
- 甲乙の会社名（正式名称）
- 住所
- 代表者役職・氏名
- 押印欄（代表者印のスペース）
- 契約締結日

---

## 5. 発注単位・単価改定

**指摘想定**：
> 発注単位（月間○○ID、○○ID単位での追加）を明確にし、単価改定の条件を記載してください。

**標準文例**：
```
1. 発注単位は、月間○○IDを最低単位とし、追加発注は10ID単位とする。
2. 単価は、本契約締結時は別紙のとおりとする。
3. 単価の改定は、経済情勢の著しい変動等やむを得ない場合に限り、
   甲乙協議の上、3ヶ月前の書面通知をもって行う。
```

---

## 6. 独占販売権・専売権

**指摘想定**：
> 独占販売権・専売権を付与する場合は、期間・エリア・最低数量のいずれかを必ず条件化してください。

**改定方針**：
- 期限付きの独占権（例：初年度のみ独占、以後は非独占）
- 最低販売数量達成を条件とする独占権

---

## 7. 契約期間・自動更新

**指摘想定**：
> 自動更新条項には、更新拒絶通知の期限を明記してください。

**標準文例**：
```
本契約の有効期間は、本契約締結日から1年間とする。
但し、期間満了の3ヶ月前までに甲乙いずれからも書面による更新拒絶の
申出がない場合、本契約は同一条件にてさらに1年間自動的に延長され、
以後もこれと同様とする。
```

---

## 8. 販売条件・価格設定の自由度

**指摘想定**：
> 販売価格を先方が強制する条項は独禁法（再販売価格維持）の観点から要注意です。

**改定方針**：
- 希望小売価格の設定は可
- 実販売価格の強制は不可（「推奨」等の表現に）

**標準文例**：
```
乙は、甲に対し、別紙のとおり本件商材の希望小売価格を提示する。
但し、甲は、当該価格に拘束されず、自己の判断により販売価格を決定する
ことができる。
```

---

## 9. 販売報告・監査権

**指摘想定**：
> 販売報告義務の範囲と監査権の条件を明確にしてください。

**標準文例**：
```
1. 甲は、毎月○日までに、前月の販売実績（販売先、販売数量、販売価格）を
   乙に書面又は電磁的方法により報告する。
2. 乙は、合理的な事由がある場合に限り、甲に対し、販売実績に関する
   関連資料の開示を求めることができる。但し、その頻度は年○回を超えない
   ものとし、甲の通常業務に支障が生じないよう配慮する。
```

---

## 10. 先方弁護士チェック後の再確認

**指摘想定**：
> 先方の弁護士チェックが入った版は、内容が大きく変わっている可能性があるため、
> 全条項の再確認が必要です。

**対応方針**：先方弁護士が入った版は、当初の法務確認済み版との差分を必ず法務に再提示する。
