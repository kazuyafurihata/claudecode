# 人材紹介契約・日々紹介基本契約 指摘パターン

## 1. 賃金立替払いは認めない

**指摘想定**：
> 賃金立替払いの利用は認めません。関連する条文・内容は全削除してもらってください。
> 「条文を残して利用しないだけにする」という運用でカバーする方法は認めません。
> 関連条文は削除してください。
> なお、賃金の支払い方法は一部門が決定して良いはずがなく、こういった筋違いのことはしないでください。

**検出ポイント**：
- 「賃金立替代行」「立替賃金相当額」等の記述
- 紹介元が候補者に賃金を立替払いする仕組み

**改定方針**：関連条文を**全削除**。残置による運用回避は不可。

---

## 2. 「稼働」→「入社」「就業」への統一

**指摘想定**：
> 従業員前提の人材紹介契約と理解していますが、随所に「当該候補者が稼働した」という
> 変わった（不可解な）表現があります。手数料等箇所でしたら普通は
> 「当該候補者が入社した」とするのが普通かと思いますので、
> 特別な意味がない限り全て直してもらってください。

**NG → OK**：

| 契約種別 | NG | OK |
|---------|-----|-----|
| 従業員採用の人材紹介 | 稼働 | 入社 |
| 派遣・アルバイトの紹介 | 稼働 | 就業、勤務開始 |
| 業務委託形態 | 稼働 | 業務開始、契約開始 |

---

## 3. 紹介手数料の算定基準

**指摘想定**：
> 紹介手数料の算定基準と対象期間を明示してください。永続課金となる場合は
> 事業採算に重大な影響を与えるため、必須の修正です。

**標準文例（日々紹介・スポット紹介）**：
```
紹介手数料は、当該候補者の入社（又は就業開始）月の賃金の30％（税抜）とし、
初回入社月の賃金を基準として一括で計算する。
以後の期間について継続的な紹介手数料は発生しないものとする。
```

**標準文例（月次課金型）**：
```
紹介手数料は、当該候補者の業務委託料月額の30％（税抜）とし、
候補者の就業開始月から起算して12ヶ月を上限として支払う。
13ヶ月目以降は紹介手数料の支払義務は発生しないものとする。
```

## 4. キャンセル料の除外規定

**指摘想定**：
> 候補者起因のキャンセルを甲の負担とするのは不当です。除外規定を設けてください。

**標準文例**：
```
甲の都合により、採用を取り消した場合、甲は乙に対し、
紹介手数料の50％相当額をキャンセル料として支払う。
但し、以下の事由によるキャンセルはこの限りではない。
 ① 候補者の自己都合による内定辞退
 ② 候補者の経歴詐称その他の候補者の責に帰すべき事由
 ③ 不可抗力（疾病・事故等）による就業不能
```

---

## 5. 通知期限の明確化

**指摘想定**：
> 通知期限が「速やかに」と曖昧です。営業日数で明示してください。

**標準文例**：
```
甲は、当該候補者の採用を決定した場合、決定日から5営業日以内に、
乙に対し書面又は電磁的方法により通知する。
当該期限内に通知がない場合、紹介手数料の発生はないものとする。
```

---

## 6. 損害賠償の相互上限

**指摘想定**：
> 乙の甲への賠償には上限（紹介手数料総額）が設けられているのに
> 甲は無制限となっており不均衡です。甲側にも同様の上限を設けるべきです。

**標準文例**：
```
本契約に基づく甲又は乙の相手方に対する損害賠償責任の総額は、
甲乙いずれにおいても、当該損害発生日の属する月から遡って
過去12ヶ月間に乙が受領した紹介手数料の総額を上限とする。
但し、故意又は重過失による場合はこの限りではない。
```

---

## 7. 遅延損害金の利率

**指摘想定**：
> 年14.6%は商事法定利率を超える水準です。市場慣行として許容される上限ですが、
> 少なくとも年6%（民法改正後の法定利率）まで下げるべきです。

**標準文例**：
```
甲が紹介手数料の支払を遅延した場合、甲は乙に対し、
支払期日の翌日から支払日までの期間について、年6%の割合による
遅延損害金を支払うものとする。
```

---

## 8. 相殺条項の相互付与

**指摘想定**：
> 現行は乙のみが自由に相殺・充当指定できる一方的な規定です。
> 甲にも同等の権利を付与する対称な条項にすべきです。

**改定例**：
```
現行：乙は、甲に対する債権を、甲に対する債務と相殺することができる。

改定：甲及び乙は、相手方に対して有する債権を、相手方に対する債務と
相殺することができる。
```

---

## 9. 準拠法・管轄

**指摘想定**：
> ライトアップ本社は東京渋谷区のため、東京専属合意管轄が訴訟コスト・利便性の
> 観点から合理的です。

**標準文例**：
```
1. 本契約は日本法に準拠し、解釈されるものとする。
2. 本契約に関して紛争が生じた場合、東京地方裁判所を第一審の専属的
   合意管轄裁判所とする。
```

---

## 10. デフォルト公開→オプトインへ

**指摘想定**：
> デフォルト公開（オプトアウト）方式は情報管理の観点から変更が必要です。
> デフォルト非公開（オプトイン）へ転換してください。

**改定例**：
```
現行：
甲は、候補者情報を当社の業務提携先へ共有するものとする。
候補者が拒絶する場合は、書面によりその旨を通知する。

改定：
甲は、候補者情報を当社の業務提携先へ共有する場合、
事前に当該候補者から書面（電磁的方法を含む）による同意を取得する。
同意がない場合は共有を行わない。
```

---

## 11. 候補者情報の優先順位・非公開設定

**指摘想定**：
> 第三者への共有は包括同意になっており、情報管理の観点から変更が必要です。

**改定方針**：業務提携先・第三者への共有は個別同意方式に。

---

## 12. 甲乙の配置（雛形ベース時）

**指摘想定**：
> 雛形をコピーして作成した場合、甲乙が逆になっている可能性があります。
> 商流と照らし合わせて確認してください。

**チェック項目**：
- 紹介する側／される側がどちらか
- 手数料を支払う側／受け取る側がどちらか
- 商流図と契約書の甲乙定義が一致するか

---

## 13. 人材紹介業法上の留意事項

**指摘想定**：
> 有料職業紹介事業の許可を受けていることが前提です。
> 許可番号の記載と、職業安定法の規定遵守を明記してください。

**標準文例**：
```
乙は、職業安定法に基づく有料職業紹介事業の許可
（許可番号：○○-ユ-○○○○○）を受けていることを表明し保証する。
乙は、本業務の遂行にあたり、職業安定法及び関連法令を遵守するものとする。
```
