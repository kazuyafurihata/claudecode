# 金銭消費貸借契約書 指摘パターン

## 1. 金利の妥当性（市場金利連動）

**指摘想定**：
> 契約書の文言は良いのですが、市場金利が上昇局面の中で据え置きのままで良いのでしょうか。
> 金利の妥当性は検討していますか。

**検出ポイント**：
- 過去の契約時の金利がベースになったまま
- 市場金利（TIBOR等）の変動が反映されていない

**改定方針（AKARI案件型の算定ロジック）**：
```
金利 = 契約締結時の1MONTH_TIBOR + SMBCスプレッド（1.00%） + 当社スプレッド（0.20%）
```

**計算例（2026年4月8日時点）**：
- 1MONTH_TIBOR: 0.92873%
- SMBCスプレッド: 1.00000%
- 当社スプレッド: 0.20000%
- 合計（積算）: 2.12873%
- 調整後適用金利: **2.1%**

## 2. 返済条件

**指摘想定**：
> 返済方法（一括・元利均等・元金均等）、返済期日、別紙予定表との関係を明確にしてください。

**標準文例**：
```
第○条（返済方法）
乙（借主）は、甲（貸主）に対し、別紙「返済予定表」に従い、
元利均等の方法により、元金及び利息を返済する。
最終返済期日は令和○年○月○日とする。

第○条（期限の利益喪失）
乙が以下のいずれかに該当した場合、乙は甲からの通知催告なく、
当然に本契約に基づく一切の債務につき期限の利益を失い、
残存する元利金を直ちに支払うものとする。
 ① 返済を1回でも遅滞した場合
 ② 支払停止・支払不能となった場合
 ③ 破産・民事再生・会社更生の申立てがあった場合
 ④ 仮差押え・仮処分・強制執行の申立てがあった場合
 ⑤ 手形・小切手が不渡りとなった場合
```

## 3. 貸付条件の明確化

**指摘想定**：
> 貸付金額・貸付実行日・実行条件を明記してください。

**標準文例**：
```
第1条（貸付）
甲は、乙に対し、以下の条件により金○○円（以下「本件貸付金」という）を
貸し付ける。

 (1) 貸付金額：金○○円
 (2) 貸付実行日：令和○年○月○日
 (3) 貸付実行方法：乙の指定する銀行口座への振込送金
 (4) 利率：年○.○％（365日日割計算）
 (5) 最終返済期日：令和○年○月○日
```

## 4. 担保・保証

**指摘想定**：
> 担保・保証の有無、種類、範囲を明記してください。無担保・無保証の場合もその旨を明示してください。

**標準文例（無担保の場合）**：
```
本件貸付金について、担保及び保証人は設定しないものとする。
```

**標準文例（担保あり）**：
```
乙は、本契約に基づく債務の担保として、以下の資産について
甲を担保権者とする譲渡担保を設定する。
 (1) ○○社（乙が保有）の株式 ○○株
 (2) 乙の所有する○○の不動産
担保設定契約は、本契約と同日付で別途締結する。
```

---

## 5. 貸付変更覚書（変更覚書との連動）

**指摘想定**：
> 金銭消費貸借契約変更覚書も、本契約と併せて確認してください。
> 金利変更がある場合は変更覚書にも同じ金利を適用してください。

**チェック項目**：
- 変更前の元金残高
- 変更後の返済予定表
- 金利の変更有無
- 期限の変更有無

---

## 6. 資金使途の制限

**指摘想定**：
> 資金使途を明記してください。転貸・他用途への流用を禁止する条項があると望ましいです。

**標準文例**：
```
乙は、本件貸付金を、○○の用途（例：運転資金、設備投資、特定プロジェクト）
にのみ使用するものとし、他の用途に流用し、又は第三者に転貸してはならない。
```

---

## 7. 経営状況の報告義務

**指摘想定**：
> 借主の経営状況報告義務を設けてください。

**標準文例**：
```
乙は、本契約期間中、甲に対し、以下の報告を行うものとする。
 (1) 四半期ごとの試算表（翌月末までに）
 (2) 年度決算書類（決算期から3ヶ月以内に）
 (3) 重大な経営状況の変化があった場合の速報
```

---

## 8. 遅延損害金

**指摘想定**：
> 遅延損害金は年6%（法定利率）程度が相場です。

**標準文例**：
```
乙が本契約に基づく返済を遅滞した場合、
乙は甲に対し、遅滞した元金に対して年6%の割合による遅延損害金を支払う。
```

---

## 9. 準拠法・管轄

**指摘想定**：
> 管轄は東京地方裁判所を専属合意管轄としてください。

**標準文例**：
```
本契約は日本法に準拠し、解釈されるものとする。
本契約に関して生じる一切の紛争については、
訴額にかかわらず東京地方裁判所を第一審の専属的合意管轄裁判所とする。
```

---

## 10. 参考資料の添付

**指摘想定**：
> 貸付判断の妥当性を示す参考資料（借主の資金計画・PL等）を添付してください。

**必要書類**：
- PL及び資金繰り計画
- 定性資料（貸付理由・事業計画）
- 借主の財務諸表（直近期）
- 担保がある場合はその評価資料
