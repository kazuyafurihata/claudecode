# 覚書（契約変更・終了・CSR条項・返金等）指摘パターン

## 1. 原契約との紐付け

**指摘想定**：
> 原契約書（締結済契約書）を必ず添付してください。
> 覚書単体では内容判断ができません。

**検出ポイント**：
- 原契約の締結日・件名・稟議番号の記載がない
- 原契約との関係条項（優先順位・変更箇所の特定）がない

**標準文例**：
```
本覚書は、甲乙間で令和○年○月○日付にて締結した「業務提携契約書」
（稟議番号：2025-○○○○、以下「原契約」という）の一部を変更・補充する
ものとする。
本覚書に定めのない事項については原契約の定めによるものとし、
本覚書と原契約の内容が矛盾する場合は本覚書の定めが優先して適用される。
```

---

## 2. CSR条項（調査・監査権）の過剰要求への警戒

**指摘想定**：
> 第6条の調査・監査権や、第9条の解除・損害賠償条項など、
> 当社にとって著しく不利な条項がないか確認してください。
> AIを使用しているのでしょうか、随所にやりすぎや疑問の残る箇所があります。

**検出ポイント**：
- 調査・監査の範囲が無制限
- 是正措置要求に応じない場合の即時解除権
- 損害賠償が過大（取引規模に対して不相応）

**改定方針**：
- 調査・監査の範囲を「本契約に関連する業務に限る」等で限定
- 是正機会を必ず設ける（催告期間の設定）
- 損害賠償の上限を設定

**改定例**（桐原書店CSR覚書案件）：
```
第9条（是正措置要求に応じない場合の解除権・損害賠償請求）
現行：
甲は、乙が甲の是正措置要求に従わない場合、催告なく本契約を解除し、
かつ、損害賠償を請求することができる。

改定：
甲は、乙が甲の是正措置要求に従わない場合、30日以上の期間を定めて
書面により是正を催告することができる。
当該期間内に乙が是正を完了しない場合、甲は本契約を解除し、
これにより生じた直接かつ通常の損害の賠償を乙に請求することができる。
但し、損害賠償の範囲は、原契約に基づく過去12ヶ月間の取引額を上限とする。
```

## 3. 責任範囲の但し書き

**指摘想定**：
> 求償・賠償の条項には、自社の責に帰さない事由による損害を除外する但し書きを入れてください。

**標準文例**（個人情報取扱・CSR共通）：
```
前項の事故が乙の本覚書違反に起因する場合において、
甲が情報主体又は甲の顧客等から損害賠償請求その他の請求を受けたときは、
甲は乙に対し、その解決のために要した費用（損害賠償金を含むがこれに
限定されない）を合理的な範囲で求償することができる。
なお、当該求償権の行使は、甲の乙に対する損害賠償請求権の行使を
妨げるものではない。
但し、乙の責に帰すべき事由によらずに生じた損害についてはこの限りではない。
```

## 4. 契約終了覚書

**指摘想定**：
> 契約終了日、終了までの業務範囲、未払金の精算、秘密保持義務の残存を明記してください。

**標準文例**：
```
第1条（契約の終了）
甲乙は、原契約を令和○年○月○日（以下「終了日」という）をもって
合意解除する。

第2条（終了までの業務）
乙は、終了日までに現在進行中の業務を完了させるものとする。
詳細は別紙「業務引継書」に定める。

第3条（精算）
甲は、終了日までに発生した乙の業務委託料を、通常の支払条件にて
乙に支払うものとする。終了日以降の新規業務に関する委託料は発生しない。

第4条（残存条項）
原契約第○条（秘密保持）、第○条（競業避止）及び第○条（損害賠償）は、
本覚書による終了後も、原契約の定める期間、なお効力を有するものとする。
```

## 5. 契約変更覚書（料金・稼働時間変更等）

**指摘想定**：
> 変更内容を「変更前・変更後」の対比で明記してください。効力発生日も明確化してください。

**標準文例**：
```
第1条（変更内容）
甲乙は、原契約第○条（委託料）について、以下のとおり変更する。
 変更前：月額○○円（税抜）
 変更後：月額○○円（税抜）

第2条（効力発生日）
本覚書は、令和○年○月○日より効力を生じる。
同日前に発生した業務委託料については、原契約の定めが適用される。

第3条（その他）
本覚書で変更する事項以外については、原契約の定めが引き続き適用される。
```

## 6. 返金に関する覚書

**指摘想定**：
> 返金理由（当社側の瑕疵等）、返金額、返金期日、返金後の債権債務の取扱いを明記してください。

**標準文例**：
```
第1条（返金の趣旨）
甲乙は、原契約に基づく○○業務について、
○○（具体的な理由）に起因する瑕疵があったことを相互に確認する。

第2条（返金額）
乙は、甲に対し、既に受領した業務委託料のうち金○○円（税抜）を
返金するものとする。

第3条（返金方法）
乙は、令和○年○月○日までに、甲の指定する銀行口座に振込の方法にて
前条の金額を支払う。振込手数料は乙の負担とする。

第4条（清算）
前条の支払をもって、本件業務に関する甲乙間の債権債務は、
本覚書に定めるものを除き、一切存在しないことを確認する。
```

## 7. 事業部・スキーム提案文書への警戒

**指摘想定**：
> 覚書の修正・提案は事業部内で検討した結果を記載していますが、
> AIを使用した過剰要求がないか再チェックしてください。

**改定方針**：事業部内で再検討し、過剰要求箇所は削除。

---

## 8. 送信アドレスの運用

**指摘想定**：
> 送信アドレスは個人のものを使うのが通常です。メールの運用を確認しておいてください。

**運用ルール**：
- 法務への覚書送付は**個人アドレス**から
- 部門共通アドレス（○○_team@）からの送付は避ける
- 本人確認欄（4項目）を必ずチェック

---

## 9. CSR・サステナビリティ覚書の特殊論点

**指摘想定**：
> 親会社（学研グループ等）のCSR方針を押し付ける覚書では、
> 遵守努力義務の範囲、調査・監査権、解除権を特に注意してください。

**許容される範囲**：
- 遵守「努力」義務（結果保証ではない）
- 合理的な範囲での報告義務
- 年1回程度の調査・監査

**NGとすべき範囲**：
- 無制限の立入検査権
- 軽微な違反での即時解除権
- 親会社の方針変更への自動追従義務

---

## 10. 解約合意書

**指摘想定**：
> 解約理由、解約日、既履行部分の取扱い、未払金の処理、残存条項を明記してください。

**標準文例**（ノイアット案件型）：
```
第1条（合意解約）
甲乙は、原契約を令和○年○月○日付けで合意解約することを確認する。

第2条（解約理由）
本解約の理由は、○○（業務診断段階で効果的な解決策が提示できる状態では
ないことが発覚した等の具体的事由）による。

第3条（既履行部分の清算）
解約日までに乙が履行した業務に対する対価として、
甲は乙に対し金○○円（税抜）を支払うものとする。
これ以外に相互に債権債務は存在しないことを確認する。

第4条（秘密保持）
甲乙は、原契約第○条（秘密保持）に基づく秘密保持義務を、
本解約後も引き続き○年間負うものとする。
```
