# 共通指摘パターン（全契約書種別で必ずチェック）

## 1. 不当に不利益な条項への交渉

**指摘想定**：
> 不当に不利益な内容はしっかり交渉をお願いします。先方書式に従うとしても、当社が負担する義務・制裁が先方より重い場合は必ず交渉対象にしてください。

**検出ポイント**：
- 違約金が一方的に当社側のみ
- 損害賠償上限が片側のみ設定
- 解除権・契約解除事由が先方にだけ有利
- キャンセル料・手数料の片務的な徴収

**改定方針**：対称化。片側のみの義務・上限は、双方同等の条件に揃える。

---

## 2. 相互性（双務性）の担保

**指摘想定**：
> 甲乙で義務・権利が非対称になっています。対になる条項を追加するか、片側の過度な義務を緩和してください。

**典型箇所**：
- 秘密保持義務（片方だけに義務）
- 相殺権（片方だけに付与）
- 譲渡禁止（片方だけに制限）
- 損害賠償上限（片方だけに設定）

**改定例**：
```
現行：甲は、乙に対し、本契約に基づく債権債務を相殺できる。
改定：甲及び乙は、相手方に対し、本契約に基づく債権債務を相殺することができる。
```

---

## 3. AI生成の過剰要求への警戒

**指摘想定**：
> AIを使用しているのでしょうか、随所にやりすぎや疑問の残る箇所があります。AIを鵜呑みにしないようにしてください。不要な交渉の長期化につながります。

**検出ポイント**：
- 原契約にない条項が大量に追加されている
- 「損害賠償の範囲を拡張」等、当社に過度に有利すぎる提案
- 先方が受け入れ不可能と明らかに分かる条件

**改定方針**：本当に必要な修正に絞る。事業部内で再検討・削除。

---

## 4. 潜脱行為の禁止

**指摘想定**：
> 基本的に潜脱行為は認めません。「条文を残して利用しないだけにする」という運用でカバーする方法は認められません。関連条文は削除してください。

**検出ポイント**：
- 法令遵守が困難な条項を残して「運用でカバー」する提案
- 業法違反リスクをスキーム設計で回避しようとする記述

**改定方針**：リスクのある条項そのものを削除。運用での回避は不可。

## 14. 【定番修正】損害賠償の片務→双務化（対顧客契約）

> ⚠️ 村越氏から繰り返し指摘される最頻出パターン。対顧客契約書では必ずチェックすること。

**指摘想定**：
> 損害賠償の条項が当社（乙）のみに賠償義務を課す片務構造になっています。対顧客契約書においては、甲乙双方が賠償義務を負う双務構造に修正するのが基本パターンです。

**検出ポイント（片務の典型パターン）**：
- 「乙は甲に生じた損害を賠償する」（乙のみ義務）
- 「乙は、本サービスの利用に起因して生じた損害について責任を負う」（当社のみ責任）
- 損害賠償上限が「乙→甲」方向にしか設定されていない
- 免責・賠償制限が「甲の免責」のみ明記されている

**改定方針**：甲乙双方向の賠償義務・上限・免責を対称に揃える。

**改定例（片務→双務）**：

```
【片務（NG）】
乙は、本契約に違反したことにより甲に損害を与えた場合、
甲に対して当該損害を賠償するものとする。なお、賠償額は
本契約に基づき乙が甲に支払った対価の総額を上限とする。

【双務（OK）】
甲又は乙は、本契約に違反したことにより相手方に損害を与えた場合、
相手方に対し、直接かつ通常生じた損害に限り賠償の責めを負うものとする
（故意または重過失による場合を除く）。
なお、いずれの場合においても、賠償額は本契約に基づき
損害を与えた当事者が受領した対価の総額を上限とする。
```

**先方雛形で特に注意すべき追加パターン**：
- 先方（甲）の賠償責任を完全免除し、当社（乙）のみ無上限賠償とする構成
- 「甲は一切の責任を負わない」＋「乙は全額賠償する」が同条に並ぶ構成
→ これらは交渉必須。先方配慮の観点からも、相互免責・相互上限設定を提案する。

> ※2026-10-09追記：現在のWU方針では故意・重過失の除外（括弧書き）は置かない。§16 を優先すること。

---

## 15. 【定番修正】損害賠償上限額の設定有無と基準

**指摘想定**：
> 損害賠償上限が当社に対してのみ設定されていない、または上限額が取引金額と不釣り合いです。

**検出ポイント**：
- 上限が「支払済み対価」の根拠なく固定金額で設定されている
- 上限なし（無制限賠償）の状態になっている
- 先方の上限のみ設定し、当社の賠償は無制限になっている

**標準的な上限基準（業界慣行）**：
```
賠償額の上限 = 損害発生月の前月末日時点での当該契約に基づく
              受領済み対価の累計額（または直近12か月分の対価合計額）
```

**ただし以下の場合は上限なし可**：
- 故意・重過失による損害
- 第三者の知的財産権侵害
- 個人情報漏洩

> ※2026-10-09追記：上限なしとするのは例外扱い。故意・重過失は原則として上限を外さない（上限額が小さい場合を除く）。個人情報の違反は相手方の責任による場合に上限の対象外とする（patterns-gyomu-teikei §14）。§16 参照。

## 16. 【2026-10 方針】損害賠償の標準形（WU確定方針）

**指摘想定**（宮原氏コメント）：
> いつものWU様方針のとおり、範囲の限定を明示し、故意・重過失のカーブアウトは置いていません。

**標準形（2層構造・双務）**：
```
1. 甲または乙は、本契約に違反し相手方に損害を与えた場合、相手方に現実に生じた
   直接かつ通常の損害に限り賠償する責任を負う。ただし、逸失利益、機会損失、
   間接損害および弁護士費用は含まないものとする。
2. 前項に基づく損害賠償の累計額は、損害の原因となった事由が生じた時点から遡って
   過去12か月間に（相手方が支払った対価）の総額を上限とする。
```
- 除外範囲は **逸失利益・機会損失・間接損害・弁護士費用** の4点をセットで明記する（「弁護士費用」の抜けが頻出）
- **故意・重過失のカーブアウトは置かない**（§12・§14の括弧書き「故意または重過失による場合を除く」は現方針では入れない）
- 上限の基準：継続取引＝過去12か月の対価総額／個別契約型＝当該個別契約の委託料総額／利用規約＝過去6か月の利用料総額

**例外**：
- **NDA**：範囲の限定だけを入れて、上限は設けない（legal:22041/22048）
- **上限額が小さい場合**（例：上限37.5万円）：故意・重過失は上限の対象から外す（legal:21974）
- **無償の取引**：上限の基準がないため、上限条項は見送る（legal:21979）
- **先方が故意・重過失の例外を求めてきた場合**：故意・重過失のときは上限だけを外し、直接損害への限定は残す形で着地させる（legal:22043）
- 「一切の損害（弁護士費用、調査費用…を含む）」のような先方案は、上記の標準形に置き換える
- **損害賠償条項がない契約書**（NDA・利用規約・申込書を含む）には追加する。反社条項の「解除による損害は賠償しない」と矛盾しないよう、冒頭に「本規約に別段の定めがある場合を除き」と入れる（legal:22046）

**出典**：legal:22056 / 22040 / 22023 / 22043 / 22015 / 21982 / 21979 / 21974 / 22041 / 22048 / 22046 / 22005

## 17. 解除条項：催告解除と無催告解除の分離

**指摘想定**：
> 些末な違反で即時解除・期限の利益喪失に至るリスクを抑えるため、催告解除と無催告解除を分離しています。

**検出ポイント**：
- 「本契約のいずれかの条項に違反したとき」が無催告解除の号に入っている
- 解除権が片側（甲のみ）にしかない
- 「長期間連絡が取れない」など、期間があいまいな解除事由

**改定方針**：
- 第1項＝催告解除（書面で相当の期間（例：30日）を定めて是正を催告し、是正されないとき）、第2項＝無催告解除（倒産、反社、虚偽、重大な違反など）
- 甲乙の双務にする。期間は「30日以上連絡が取れない場合」のように具体化する
- 解除を原因とする終了は、終了後の報酬支払義務の対象から外す（「ただし、乙が第◯条に基づき本契約を解除した場合は、この限りでない」）

**出典**：legal:22056 / 22023 / 21979 / 21982 / 22037

## 18. 反社会的勢力の排除は独立した条文で

**改定方針**：解除事由の1号として入れるのではなく、独立した条文にする。
```
1. 甲および乙は、自己（役員、実質的に経営を支配する者を含む。）が反社会的勢力に
   該当しないことを表明し、将来にわたっても該当しないことを確約する。
2. 甲または乙は、相手方が前項に違反した場合、何らの催告を要せず直ちに本契約を解除できる。
3. 前項により解除した当事者は、相手方に生じた損害を賠償する責を負わない。
```
- 解除条項の側は「第◯条第1項の表明保証に違反したとき」と参照する形にする

**出典**：legal:22056 / 22023

## 19. 存続条項は条番号で明示する

**指摘想定**：
> 「存続する規定に係る本覚書の定め」では範囲が不明確でしたので、存続する条項を明示しました。

**検出ポイント**：
- 存続条項がない
- 「本契約終了後も存続する規定」のように、どの条項か特定されていない
- 「永続的に」など、法的に不明確な表現（存続条項があれば不要なので削除する）

**改定方針**：秘密保持・損害賠償・反社免責・直接取引禁止・知的財産・個人情報・管轄・存続条項そのものを、条番号で列挙する。秘密保持の存続期間は **WU基準の3年**。

**出典**：legal:22056 / 22040 / 22043 / 22023 / 21982

## 20. 取適法（中小受託取引適正化法）・フリーランス法への対応

**指摘想定**（村越氏）：
> 取適法が施行されてもうすぐ1年ですが、Claudeは下請法からのアップデートが苦手のようです。

**検出ポイント**：
- 「下請代金支払遅延等防止法」「下請法」「下請」など旧法の名称・用語が残っている（AIが作った文案で頻出）
- 個人や小規模事業者への委託で、発注書面に支払条件が書かれていない

**改定方針**：
- 法令名・略称は「中小受託取引適正化法」「取適法」に置き換える（村越氏の実際の修正どおり）
- フリーランス法の書面交付義務を満たすため、注文書の記載事項に「支払条件」を入れ、承諾の方法を「書面（電磁的方法を含む。）により」と明記する
- 支払いの起点は「適正な請求書の受領後」とする（請求書に不備があったときの支払遅延を当社の責任にしない）
- ⚠️ 定義語（委託事業者／中小受託事業者 など）や支払期日の規律は、条文に合っているか法務の確認が必須。AIの知識だけで確定させない

**出典**：legal:22023（H社ディレクション型）／22064（平塚さん・取適法対応の巻き直し）

## 21. 定義・参照・別紙の整合

**検出ポイント（今期の実例）**：
- 定義と本文が食い違う：「24時間365日の一次対応」（定義）と「標準保守対応時間 平日10〜19時」（第5条）（legal:22040）
- 条番号の参照ミス：「次条に定める違約金」が実際には第5条第1項にある（legal:22043）／「第3条」と「第2条」の引用が混在（legal:21974）
- 本文と別紙で金額の基準が違う：本文は「支払われた報酬額の50％」、別紙は「設定した報酬額の50％」（legal:22061）
- 別紙の注記に一方的に改訂できる文言があり、本文の30日前通知と矛盾する（legal:22044/22061）
- **別紙の肝心な条件の記入漏れ**：販売金額・報酬額・支払条件・支払日が空欄（legal:22037。村越氏「肝心な箇所の記入漏れがあります」）
- 未定義の用語（「本件協業」「本件業務」）→ 定義済みの語に差し替える（legal:21976）
- 「支払い条件」と「発生条件」の混同 → 報酬の発生要件なら「発生」（村越氏の定番修正）

**改定方針**：定義・本文・別紙のどれか一つに揃え、注記は本文の手続を参照する形にする。

## 23. 原契約との関係（覚書・解約合意書・変更合意書）

**検出ポイント／改定方針**：
- **基本契約の解約合意書**：検収・支払条件が基本契約側にある場合、解約すると進行中の個別契約と未払いの委託料にルールがなくなる → 「解約日までに成立した個別契約には引き続き原契約を適用」「既発生の債権債務は存続」を追加する（legal:22038）
- **覚書**：本契約との優劣（「抵触する場合は本覚書が優先」「その他は本契約が有効に存続」）を定める（legal:22057）
- 原契約に過去の覚書があるときは「◯年◯月◯日付覚書による変更を含む」と特定する（legal:22004）
- 紛争解決の覚書：「請求しない」という約束だけでなく「請求権を放棄する」と書く。「金額の多寡を問わない」を加える。請求の停止は権利放棄でないことを明記する。先方に通知義務を課す（入金確認の起点）。協議中は請求や訴訟をしないことを定める（legal:22057・顧問弁護士）

## 24. 法務からの戻しの扱い・依頼の要否（事務）

- 「WU様宛コメント※先方提示時には削除」や顧問弁護士のコメントは、**先方に出す前に必ず削除する**。説明を求められたら参考にして回答する（legal:22057）
- 法務の修正に「社内運営上問題なければ元に戻してよい」と書かれた箇所は、事業部が判断してよい（legal:21982）
- **見積書・注文書**：取引条件の記載がなければリーガルチェックの対象外（rakumoでは稟議の添付書類として扱う）。裏面に約款がある場合は、注文書を取り寄せてから依頼する（legal:21999 / 22002）
- 電子署名は当社で設定する。先方の署名者アドレスを入手し、**それぞれの会社のドメインか確認する**（legal:22032）
- 契約の成立（注文→承諾）は文書で行い、あいまいにしない。支払いは「注文→履行→検収→請求→支払」のサイクルに沿わせる。支払いが二つに分かれる前払いは原則認めない（legal:22015）
- 依頼メールに書いた取引関係（どちらが委託でどちらが受託か）と、契約書の甲乙の構造が一致しているか確認する（legal:22041）
