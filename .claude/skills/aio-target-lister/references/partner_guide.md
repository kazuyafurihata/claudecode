# AIO提案先リスター 使い方ガイド

利用者から使い方を聞かれたときに、この内容で答える。聞かれた部分だけを短く返し、
全文を貼らない。

## ひとことで言うと

Gmailの「送信済み」を読んで、**過去にメールを送ったことのある会社**を全部洗い出し、
AIOマスターを提案しやすい順（S・A・B・C）に並べた台帳を作ります。
所要時間は10〜20分ほど。その間、Claudeが進み具合を知らせます。

## 必要なもの

| もの | 確認方法 |
|---|---|
| Claude Code（デスクトップアプリのCodeタブ） | アプリ左上で「Code」を選べる |
| Gmailのコネクタ | claude.ai の「設定」→「コネクタ」に Gmail がある |
| Python 3 | なくてもClaudeが確認して、入れ方を案内します |

## 導入（最初の1回だけ）

1. 配布された `aio-target-lister.skill` を手元に保存する
2. Claude Code に次のように送る
   「ダウンロードフォルダの aio-target-lister.skill をスキルとして登録して」
3. 登録が終わったら、Claude Codeをいったん閉じて開き直す

手動で入れる場合：`.skill` はZIP形式です。展開してできた `aio-target-lister` フォルダを
`（ユーザーフォルダ）/.claude/skills/` の中に置きます。

## 使い方

Claude Code で次のどれかを送るだけです。

- 「AIOの提案先リストを作って」
- 「送信済みメールから提案先を出して」
- 「直近4か月分で提案先リストを作って」（期間を変えたいとき）

途中でGmailの読み取り許可などを聞かれたら「許可」を選んでください。
メールを送ったり、削除したりすることはありません。

## できあがるもの

`ドキュメント/AIO提案先台帳/<日付>/AIO提案先台帳.html`
ダブルクリックするとブラウザで開きます。

一覧表がほしいときは、台帳の上部にある「CSVをダウンロード（Excel可）」を押してください。
Google Driveをつないでいれば、Googleスプレッドシートも自動で作られ、台帳の「スプレッドシートで開く」から開けます
（スプレッドシートは自分のマイドライブに保存され、自分しか見られません）。

### 台帳の見方

1社ごとに「会社名 / 担当者名 様 / メールアドレス」の3段で表示されます。

| 項目 | どこから取っているか | 確からしさ |
|---|---|---|
| 会社名 | 相手の返信や宛名にある「株式会社〇〇」 | 出てこなければアドレスの@より後ろを表示。別の社名を拾うこともあるので連絡前に確認 |
| 担当者名 | 自分が送ったメールの書き出し「〇〇さま」 | 自分で書いた宛名なので、ほぼ正確 |
| メールアドレス | 実際に送った宛先 | 事実。複数あればやりとりの多い人を表示し、注記に「他N名の宛先あり」 |

| 表示 | 意味 | 今日の動き方 |
|---|---|---|
| **S** いま出せば決まる | AIOの話が動いている、または取引が進行中 | 追いかけの連絡。最終接触からの日数を見て、空いている順に |
| **A** 非指名検索が売上に直結 | お客様が「地域＋業種」でAIに聞く業種 | 新規提案。台帳の注記にある件名を使って話を切り出す |
| **B** 掲載価値はあるが自社導入型 | 来店・来院型の地元ビジネス | 単体導入の提案 |
| **C** AIOより先に別の話題 | 件名からAIOの文脈が読み取れなかった先 | 近況確認から。「向いていない」という意味ではありません |

| 印 | 意味 |
|---|---|
| `AIO` | AIOの商談がすでに動いている |
| `確` | メールの件名から業種が確認できた |
| `推` | メールアドレスからの推定。**連絡前にその会社のホームページを見て確認してください** |

上部のボタンで業種ごとに絞り込み、検索欄で社名を探せます。
「再販・紹介」は、その会社自身が多くのお客様を持っていて、紹介してもらえる可能性がある先です。
紹介の条件はライトアップの担当者に相談してから提案してください。

## 作ったあとにやること

> ①リストを作る（済） ②S〜Bから20社選ぶ ③上から3件、明日連絡する

1日3件で月60件の接触になります。月に1回作り直すと、新しく取引が始まった会社も拾えます。
「1社目への連絡文の下書きを作って」と頼めば、下書きまで作ります（送信はしません）。

## よくある質問

**Q. メールの中身は外に出ませんか？**
読むのは送信済みメールの宛先・件名・日付までです。台帳はあなたのPCの中にだけ保存されます。
台帳には取引先の社名と件名が載るので、社外には共有しないでください。

**Q. 受信メールの相手は入らないのですか？**
入れていません。AIOは初対面の相手に提案すると警戒されやすいため、自分から連絡したことのある相手に絞っています。

**Q. 業種が間違っている会社があります。**
`推` の付いた会社はメールアドレスからの推定です。「◯◯社は歯科医院なのでAに移して作り直して」と送れば直します。

**Q. 会社名が空欄（アドレスの一部）／違う会社名になっています。**
会社名はメールに「株式会社〇〇」と書かれていた場合だけ出ます。「〇〇.co.jp は株式会社△△なので直して」と送れば直します。

**Q. 直近1年は知っている会社が少なく、リストが短いです。**
「4年分で作って」と期間を広げてください。途中でアドレスが変わった場合は「旧アドレスの送信分も含めて」と添えれば両方読みます。不在中の自動返信は自動で除外されます。

**Q. ライトアップとのやりとりが入っていません。**
提供元なので、提案先から外しています。

**Q. 途中で止まった／エラーが出た。**
そのまま「エラーが出た」と送ってください。原因を調べて続きから再開します。
それでも解決しない場合は、画面の文言を控えてライトアップの担当者に連絡してください。
