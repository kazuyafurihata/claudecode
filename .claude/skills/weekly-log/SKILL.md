# 週次ログ（weekly-log）

テキストで残した週次ログをもとに、記録とリマインドを行う。ログは `weekly/YYYY-MM-DD.md`（その週の月曜日の日付）。

## 記録するとき
1. `scripts/new-week.sh` を実行して今週のファイルを用意する（先週の「来週に延ばしたこと」は自動で引き継がれる）。
2. ユーザーの話（音声入力の書き起こしでもOK。フィラーや言い間違いは整えてよい）を次の形に整理して追記する。
   - 「今週やること」: `- [ ] （担当）やること` — 担当が分からなければ `（自分）`
   - 「来週に延ばしたこと」: `- （担当）やること — 理由`
   - それ以外の決定事項・話題は「メモ」へ
3. 話に出ていないタスクや担当、期限を創作しない。曖昧な点は一言確認する。
4. 完了報告を受けたら `- [ ]` を `- [x]` にする。

## 聞かれたとき（「今週やることは？」など）
1. 今日を含む週のファイル、なければ最新のファイルを読む。
2. 未完了（`- [ ]`）を担当ごとにまとめて返す。持ち越し分は明示する。
3. 「先週延ばしたことは？」なら前週ファイルの「来週に延ばしたこと」を返す。
4. ログにないことは「記録がない」と答え、推測で埋めない。
